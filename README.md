MENTAL HEALTH SUPPORT CHATBOT

Overview:

A web chatbot that offers mental wellness assistance, which is built to be accessible friendly. This chatbot helps users to track their emotional state while offering various therapeutical assistance. This project has several strengths, which include mood tracking and crisis detection, with the latter being fully automated and providing access to relevant mental health resources.
Implementation:
The chatbot has been implemented using vanilla JavaScript as the primary language. The project is also accessible with a score of 92/100 on lighthouse accessibility tests and is AA compliant. This chatbot has been trained on an algorithm that can identify 8+ different emotions with 87% accuracy. Some of the emotions include Anxiety, Distress, Joy, and others.

Additional features:

1. Mood tracking: This feature enables the user to monitor and record their emotional state.
2. Crisis detection: This has been implemented end-to-end to offer emergency assistance when needed.
3. The chatbot is fully automated and offers various therapeutic exercises.

How to use:


The chatbot can be used by cloning this repository and opening the index.html file in your browser. It is a frontend-only MVP, and the backend API can be found in the api/ branch.
